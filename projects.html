Li-ion battery thermal anomaly detection

Research — unsupervised learning on thermal imaging data

A hybrid pipeline for spotting abnormal heating in EV battery cells. Engineered temperature and gradient features plus autoencoder reconstruction error, reduced with PCA, then scored anomalies by combining KMeans clustering with a convolutional autoencoder. Hyperparameters tuned with Optuna; evaluated on ROC-AUC, F1 and recall. Accepted at IEEE TENCON 2026.

Python, scikit-learn, TensorFlow/Keras, Optuna

Citation Knowledge Agent

Tsinghua GenAI Summer School — LLM agents, knowledge graphs

A browser-driving agent that verifies citations: it retrieves each cited source, cross-checks the claim against it, and records the result in a knowledge graph served over MCP.

Playwright MCP, GLM (z.ai API), knowledge graphs

Floket

EMG signal detection system

Hardware — embedded systems, analog electronics

A low-cost electromyography rig: surface electrodes into an LM324-based amplification stage, read by an Arduino Nano, with threshold-based processing for real-time muscle-activation response.

Arduino Nano, LM324, analog signal conditioning
